# Exmen parcial

En este proyecto apliqué los pilares de la Programación Orientada a Objetos para crear un sistema de inventario organizado. Utilicé encapsulación al declarar los atributos como privados y acceder a ellos mediante propiedades, lo que asegura que los datos del producto estén protegidos. También implementé herencia para que las clases de electrónicos y alimentos reutilizaran el código de la clase base, evitando repetir variables comunes como el nombre o el precio.

Lo más interesante fue aplicar el polimorfismo con el método de impuestos. Como estudiante, me di cuenta de lo útil que es definir un método como virtual en la clase padre y luego usar override en las clases hijas; esto permite que el programa sea inteligente y sepa si debe aplicar el 18% de ITBIS o el 8% de alimentos automáticamente. Es una forma muy eficiente de programar, ya que el código queda mucho más limpio, profesional y fácil de mantener.
